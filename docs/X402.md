# x402 at AIFoundry

Astras.ai brand. Prepaid only.

1. Agent hits `POST /v1/tools/{name}`.
2. No payment → HTTP 402 with `payTo`, network, price.
3. Facilitator verifies (`https://x402.org/facilitator`).
4. Worker grants T10K / M10 session headers.
5. Upstream models stay on operator prepaid keys — never in the client.

Do not copy `PAY_WALLET` from the demo gateway. That address is a public example.
